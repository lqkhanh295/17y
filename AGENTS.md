# Project Rules for AI Agents

All AI assistants (Antigravity, Cursor, Claude Code, etc.) operating in this workspace must adhere to the integrated UI/UX guidelines:

## Integrated Skills
- **UI/UX Pro Max**: `.agents/skills/ui-ux-pro-max/` (Search scripts: `.agents/skills/ui-ux-pro-max/scripts/search.mjs` or `search.py`)
- **Taste Skill (v2)**: `.agents/skills/design-taste-frontend/` (Art direction: `node .agents/skills/design-taste-frontend/scripts/draw.mjs`)
- **Awesome UI**: `.agents/skills/awesome-ui/` (High-craft frontend patterns & token system)

## Development Directives
1. **Never produce generic AI template slop**: Reject boilerplate centered heroes, 3-card icon rows, and weak lavender/purple gradients.
2. **Consult UI/UX Pro Max**: Use the local BM25 search script for color palettes, font pairings, chart selection, and stack guidelines.
3. **Use Taste Skill**: Follow the anti-slop house style with high-contrast typography, real imagery/content, and section variety.
4. **Awesome UI Craftsmanship**: Ensure every button and input has 6 states (default, hover, active, focus-visible, loading, disabled) with tactile micro-interactions.
5. **Accessibility**: Enforce WCAG 2.2 AA standards (4.5:1 contrast, 44x44px touch targets, visible focus rings, keyboard navigability).
